# Ideas

## Hidden grouping-property challenge

Show a scatterplot with many icons. Each icon has several visible attributes, such as color, shape, size, border color, fill pattern, or another playful visual feature.

The whole dataset has a visible trend in one direction. The challenge is to find which property can be used to split the icons into groups where every subgroup trend points in the opposite direction.

Possible interaction:

- User picks an attribute: color, shape, size, border, fill, etc.
- The plot redraws subgroup trend lines for that attribute.
- The goal is to discover the attribute that creates a Simpson's Paradox reversal.
- This could become a bridge between the fish trend-line chapter and later examples, because it turns "look for hidden groups" into an active search.
